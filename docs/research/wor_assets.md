## Path conventions

- Textures: `E:\Dev\ghwt\ghwor-extract\z_in_game_png2\<name>.png` (call it `Z\`) and `...\ui_shared_png2\<name>.png` (`U\`).
  `*_png` folders hold the same names but are GHSDK output (unreliable for X360, MODLOG); use `*_png2`.
  Names in the two folders are disjoint, so the folder is given once per row as Z or U.
- Descs already decompiled: `E:\Dev\ghwt\ghwor-extract\uidesc\uidesc_<name>.txt` (z_in_game descs only).
- **The ui_shared descs were NOT decompiled in the extract** (player_meter / competitive score bar, place badge, instrument
  icon container, gamertag, vocal meters, fail vignette). I decompiled them with `node guitar-hero-sdk\sdk.js decompile` from
  `ghwor-extract\all\x\compressed_PAK_ui_shared\ui\*.qb.xen` into
  `E:\Dev\ghwt\ghwt-wor-hud\docs\research\ui_shared_desc\uidesc_<name>.txt` (24 files, `UI\` below). Nothing else was modified.
- Scripts: `E:\Dev\ghwt\ghwor-extract\hudqb\` (`scripts__guitar__hud__hud_widgets.txt` = `HW`,
  `scripts__guitar__hud__guitar_highway_hud.txt` = `GHH`, `scripts__game__goals__goal_hud.txt` = `GOAL`,
  `scripts__guitar__vocals_highway.txt` = `VH`). Strings: `all\x\compressed_PAK_qs\scripts\guitar\vocals.qs.xen`.
- Note: the nixie multiplier art (`HUD_score_nixie_*`, `band_hud_score_*`, `higway_icon_*`) is NOT a WoR extract texture; it is
  GH3:WoR (DE_EXTRACT). WoR's own multiplier is the `HUD_meter_combo` bubble (below).

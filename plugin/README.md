# HUD fixes plugin (wor_hud_fixes.asi)

Native fixes for the GH5 / WoR HUD theme that data can't reach. Loaded by
[Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader) (`dinput8.dll`, x86) from the game folder.
In-memory patches only: every patch site is byte-checked against the known GHWT_Definitive.exe and the plugin stays
inert on any mismatch. It writes `wor_hud_fixes.log` next to the exe.

Fixes (only for the WoR theme's widgets; every other theme runs the game's own code):
1. Note-streak lights in WoR's colours (x1 pink, x2 orange, x3 green, x4 purple, star power blue), using the mod's own
   texture names so the stock lights can't replace them from the 2nd song on.

Build: `build.bat` (Visual Studio 2022+ C++ x86 tools) -> `build\wor_hud_fixes.asi`. `src/names.h` is generated by
`python tools/gen_plugin_names.py`. Reverse-engineering notes: `docs/PLUGIN_NOTES.md`.
